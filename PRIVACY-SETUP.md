# Privacy before publishing

1. In GitHub account Settings → Emails, enable **Keep my email addresses private** before uploading. GitHub web commits then use a noreply address. Optionally block command-line pushes that expose your email.
2. Check your public GitHub profile and remove optional identifying fields you do not want public. Your GitHub username remains visible.
3. Upload only the generic app files. Never upload exported collection workbooks or JSON recovery files to the public repository.
4. Public visitors can see the app and source, not the collection saved in another browser. An unlocked shared browser profile can see its local collection.
5. GitHub Free Pages is public hosting. There is no sign-in or automatic online collection storage in this edition.
6. The new app files contain no personal name, email, profile, prior conversation details, or collection. They do not remove old repository history. A clean new repository after enabling email privacy avoids carrying the old commits into the new repository. Deleting/privatizing the old repository does not recall copies already downloaded.
7. Use Download recovery backup to keep your collection and move it between devices. Excel export is a readable inventory, not an app restore file.
